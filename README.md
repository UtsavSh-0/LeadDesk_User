# LeadDesk User Portal

LeadDesk User Portal allows users to create and manage leads, appointments, support tickets, and personal profile information through a modern and responsive interface.

## Features

- User Registration
- Secure Login
- Email Verification
- Forgot Password
- Dashboard
- Lead Tracking
- Appointment Booking
- Support Ticket System
- Profile Management
- Notification System
- Responsive UI

## Tech Stack

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Shadcn UI

## Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/user-portal.git
```

Move into project

```bash
cd user-portal
```

Install dependencies

```bash
npm install
```

Create

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```

## Build

```bash
npm run build
npm start
```
